# 🍔 Zwigato — Full-Stack Food Ordering Application

Zwigato is a full-stack food ordering web application built using **HTML, CSS, JavaScript, Node.js, Express.js, and PostgreSQL**.

The application allows users to explore food items, browse categories, search for food, add products to their cart, manage quantities, and place orders through an interactive user interface.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structure of the application |
| CSS3 | Styling and responsive design |
| JavaScript | Frontend functionality |
| Node.js | Backend runtime environment |
| Express.js | Backend framework and REST APIs |
| PostgreSQL | Database management |
| Middleware | Request processing and handling |
| Postman | API testing |
| Git & GitHub | Version control |

## ✨ Features

1. 🍕 **Food Menu:** Browse available food items with images and details.
2. 🔍 **Food Search:** Search for food items by name.
3. 🗂️ **Category Filtering:** Filter food items by categories such as Pizza, Burger, Biryani, Desserts, and Drinks.
4. 🛒 **Shopping Cart:** Add food items to the cart and manage cart contents.
5. ➕➖ **Quantity Management:** Increase or decrease item quantities.
6. 💰 **Dynamic Total:** Automatically calculate the cart total.
7. 📦 **Place Order:** Submit orders through the backend API.
8. 🗄️ **PostgreSQL Database:** Store and retrieve food menu data.
9. 🔗 **REST API:** Handle frontend and backend communication using Express.js.
10. 📱 **Responsive UI:** User-friendly interface for different screen sizes.

## ⚙️ Installation & Setup

Follow these steps to run Zwigato on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/ali45381/Zwigato_final.git
cd Zwigato_final
```

### 2. Install Backend Dependencies

```bash
cd backend
npm install
```

### 3. Configure PostgreSQL

- Make sure PostgreSQL is installed and running.
- Create a PostgreSQL database.
- Configure the database connection in the backend.
- Add your database credentials securely using environment variables.
- Ensure the required food table and data are available.

**Note:** Never upload your `.env` file or expose database credentials on GitHub.

### 4. Start the Backend Server

```bash
npm start
```

The backend server will start on the configured port (for example, `5000`).

### 5. Run the Frontend

Open the `frontend/index.html` file in your browser, or use the VS Code Live Server extension.

The application should now be ready to use locally.
