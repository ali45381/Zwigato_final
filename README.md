# 🍔 Zwigato – Full-Stack Food Delivery Application

Zwigato is a full-stack food delivery web application that allows users to explore food items, browse categories, add products to their cart, and place orders.

## 🌐 Live Demo

[Visit Zwigato](https://zwigatofinal-frontend-g69r.vercel.app/)

## ✨ Features

- Browse food items dynamically from a database.
- Filter food by categories.
- Search for food items.
- Add items to the shopping cart.
- Increase or decrease item quantities.
- View cart total.
- Place food orders.
- Responsive user interface.

## 🛠️ Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Node.js
- Express.js
- REST APIs

**Database**
- PostgreSQL
- Neon Database

**Deployment**
- Vercel – Frontend
- Render – Backend
- Neon – Database hosting

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/ali45381/Zwigato_final.git
```

2. Open the project folder:

```bash
cd Zwigato_final
```

3. Install backend dependencies:

```bash
cd backend
npm install
```

4. Configure your environment variables in a `.env` file:

```env
DATABASE_URL=your_postgresql_connection_string
PORT=5000
```

5. Start the backend:

```bash
npm start
```

6. Open `frontend/index.html` in your browser using a local development server.
