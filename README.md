# 🍔 Zwigato — Full-Stack Food Ordering Application

Zwigato is a full-stack food ordering web application built using **HTML, CSS, JavaScript, Node.js, Express.js, and PostgreSQL**.

The application allows users to explore food items, browse categories, add products to their cart, manage orders, and place orders through an interactive user interface.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Middleware:** Express Middleware
- **API Testing:** Postman
- **Version Control:** Git and GitHub

- ## ✨ Features

- 🍕 **Food Menu:** Browse available food items with images and details.
- 🔍 **Food Search:** Search for food items by name.
- 🗂️ **Category Filtering:** Filter food items by categories such as Pizza, Burger, Biryani, Desserts, and Drinks.
- 🛒 **Shopping Cart:** Add food items to the cart and manage cart contents.
- ➕➖ **Quantity Management:** Increase or decrease item quantities.
- 💰 **Dynamic Total:** Automatically calculate the cart total.
- 📦 **Place Order:** Submit orders through the backend API.
- 🗄️ **PostgreSQL Database:** Store and retrieve food menu data.
- 🔗 **REST API:** Handle frontend and backend communication using Express.js.
- 📱 **Responsive UI:** User-friendly interface for different screen sizes.
